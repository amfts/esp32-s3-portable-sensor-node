# Requisitos del proyecto

## Objetivos funcionales

- Disponer de un microcontrolador de bajo consumo y altas prestaciones.
    
- Alimentación autónoma mediante batería recargable.
    
- Programación y alimentación mediante USB-C.
    
- Capacidad de almacenamiento local mediante tarjeta MicroSD.
    
- Medición de variables ambientales.
    
- Medición de movimiento y orientación.
    
- Detección magnética mediante sensor Hall.
    
- Indicadores visuales mediante LEDs RGB.
    
- Acceso a GPIOs externos para futuras ampliaciones.
    

## Objetivos de diseño

- PCB compacta.
    
- Componentes SMD de bajo tamaño.
    
- Consumo reducido.
    
- Integración de todas las funciones en una única placa.
    
- Fabricación económica mediante JLCPCB.
    

## Restricciones

- Alimentación mediante una única celda Li-Ion.
    
- Componentes fácilmente disponibles.
    
- Diseño realizado como proyecto de aprendizaje y desarrollo personal.
