# ESP32-S3 Portable Sensor Node

## Status

⚠️ Rev A completed – hardware validation identified a power architecture issue. A Rev B redesign is planned.

## Features

- ESP32-S3-WROOM-1
- USB-C charging
- Li-Ion battery support
- MicroSD storage
- HDC1080 temperature/humidity sensor
- LIS3DH accelerometer
- DRV5013 Hall sensor
- WS2812 RGB LEDs

## Project Scope

This project covers the complete hardware development cycle:

- Requirements definition
- Schematic capture
- PCB layout
- Manufacturing
- SMD assembly
- Bring-up
- Hardware debugging
- Root-cause analysis
- Rev B proposal
